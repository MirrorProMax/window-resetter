## 五、口径禁区（v3 汇总）

- **画面与旁白一律不出现**：URL / 域名、二维码、平台名（GitHub / Gitee / Releases）、「简介」「评论区」「扫码」「下载」「一键安装」等导流词或话术。
- 版本号「v1.1.0」可出现（属产品事实，不是链接）；安装与权限提示只写客观要求，不写获取途径。
- 不写「自动整理所有窗口」「无需任何权限」「任何位置都自动归中」「自动帮你均分屏幕」。
- 「平板」是体验类比；不出现平板硬件 / 系统界面，不写「支持平板」「功能相同」。
- 「分屏」= 同一块屏幕的左右分屏；全片**不出现多显示器 / 跨屏 / 按窗口所在屏幕计算**。
- 自动居中默认开启、常驻后台、不用点；菜单栏点击是**可选操作**，两者不混为一谈。
- 磁吸发生在**松手之后**，范围默认 8%、可调 1~20%；靠边放就不打扰。
- 模式记忆是**本机偏好**，不引申为云端 / 跨设备同步。
- 保留：macOS 专属标注、macOS 13.0+、需「辅助功能」权限、未签名需右键打开、不联网 / 不收集数据 / MIT 开源。
- 不做竞品对比，不出现竞品名称与贬损表述。
