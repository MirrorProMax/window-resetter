# 窗口复位器 · 宣传短视频拍摄脚本

> 适用项目：WindowResetter（macOS 菜单栏窗口复位工具）
> 版本：v1.3 ｜ 2026-11-08 ｜ 主版 75 秒，附 30 秒竖屏剪辑版与抖音配音版成片

## 一、拍给谁看，讲什么

| 项目 | 内容 |
| --- | --- |
| 产品 | 窗口复位器，纯 Swift ＋ AppKit／SwiftUI 的 macOS 菜单栏小工具，无第三方依赖、不联网、不收集数据，MIT 开源 |
| 一句话卖点 | 窗口不用你摆，点一下就正 |
| 核心动作 | 左键点菜单栏图标：把当前焦点窗口按规则摆正；再点一下：在宽模式与窄模式之间切换；每个 App 各自记住自己的模式 |
| 隐性主角 | 常驻的「自适应居中」：新窗口自动居中、靠边固定不打扰、跨屏松手才居中、拉伸保持中心、中心磁吸与触控板反馈、双击窗口边缘补齐对侧 |
| 目标观众 | macOS 多任务用户、外接显示器用户、开发者与效率工具爱好者；发布渠道为项目 README、B 站、视频号、小红书 |
| 观众看完要记住 | 一个图标、一次点击、窗口就位；以及「不联网、不收集数据」 |

## 五、拍摄前准备

**环境与系统**

- 开启勿扰、关闭通知与日历弹窗；清空桌面、统一壁纸；菜单栏只保留必要图标；Dock 状态前后一致。
- 确认辅助功能权限已勾选，录制前重启一次应用，避免中途弹授权框。
- 关闭其他开机自启与后台同步，避免窗口自己跳动。

**应用设置（按镜头预设）**

| 设置项 | 第 03～06 镜 | 第 07～10 镜 | 第 11 镜 |
| --- | --- | --- | --- |
| 自适应居中 | 关（避免干扰点击演示） | 开（默认） | 开 |
| 吸附率 | — | 8%（默认） | 8% |
| 平滑变化 | 关 | 关 | 开，1000 毫秒 |
| 竖屏自适应／台前调度检测 | 关 | 关 | 按演示内容单独开启 |

**录制与实拍**

- 录屏用 QuickTime 或系统截图工具栏，60fps；指针放大，点击加后期高亮圆环。
- 实拍 B-roll：MacBook 侧 45 度、手指点击触控板特写、外接显示器入镜；避免拍到隐私内容。
- 素材命名：`WR_镜号_内容_版本.mov`，例如 `WR_04_一键摆正_v1.mov`。
- 预演：按分镜顺序完整走一遍，每个点击动作练三次，确保「点一下即到位」不出现二次调整。

## 八、口径与禁区

| 不能这么说 | 准确说法 |
| --- | --- |
| 自动整理所有窗口／一键分屏／全局窗口管理 | 对当前焦点窗口复位或切换，另有常驻的自适应居中 |
| 无需任何权限 | 需要 macOS「辅助功能」权限，片中可用一行小字说明 |
| 所有设备都有震动反馈 | 触控板反馈需相应硬件，无 Force Touch 时可能无感 |
| 默认就有动画／竖屏／台前调度适配 | 平滑变化默认关闭（默认 1000 毫秒）；竖屏自适应、台前调度检测均为可选开关 |
| 适配所有 App | 部分 App 会夹断窗口尺寸或拒绝辅助功能写入，此时以实际尺寸居中兜底 |
| 永久免费商用等商业承诺 | 仅陈述事实：MIT 开源、不联网、不收集数据、纯 Swift 无第三方依赖 |

- 隐私四句可在片中对应到 `PRIVACY.md` 与仓库源码，不夸大、不引申。
- 画面里一律使用示例文档与空白数据，不出现真实客户、账号、订单、内部路径或通知内容。
- 不做竞品对比、不出现竞品名称与贬损表述。

## 九、抖音配音版成片（v1.3 修订）

`assets/窗口复位器-抖音30秒宣传片.mp4` 为按本工具真实功能逐帧绘制的仿录屏动效，非真实录屏。

**v1.2 三处改动**：① 全片以**窗口自动居中**为主角，点击复位与宽窄切换降为「可选操作」；② 删除多显示器 / 跨屏相关表述；③ 配音换成温柔女声（Edge TTS `zh-CN-XiaoxiaoNeural`，官方标签 Warm）。

**v1.3 改动**：放慢开场字幕节奏。开场 4.8 秒原本随三个动作硬切三版字幕（每段仅 1.3–2 秒），而这段只有一句旁白，文字跑得比语音快；现改为**一句旁白配一屏固定字幕**——主字幕全程保持「窗口，自己会居中／不用点 · 默认开启」，仅开头 0.5 秒柔和淡入一次；辅助胶囊也只用一条「拖开也没关系 · 松手自己回中间」，1.25 秒淡入后保持到镜头结束。三个动作仍由画面动效表达，配音与音效完全不变。

**时间与旁白**（7 段合计约 26 秒，人声段音效自动压低）

**字幕节奏**：原则上「一句旁白 = 一屏主字幕」，字幕切换点对齐分镜起点而非画面内的每个动作。开场为节奏最缓的一段；后续镜头如需放慢，可调整 `chrome()` 的 `fade_dur`（默认 0.25 秒，开场用 0.5 秒）。

**主次关系**：前 13 秒与片尾 Slogan 都讲自动居中；第 4–6 段画面右上角统一挂「可选操作」标签，片尾把「点一下，就正了（可选）」降为小字，主 Slogan 改为「窗口，自己会回中间」。

**平台标注**：全片左上角常驻「macOS 专属」胶囊，片尾写「仅支持 macOS 13.0 及以上 · 需辅助功能权限」，与 README 的环境要求一致。

**去多屏口径**：成片字幕、旁白、说明文字均不含「多显示器／跨屏／按窗口所在屏幕计算」。第四节主版分镜里保留的跨屏镜头属于 75 秒主版脚本，与本成片无关；若也要拍主版，需另行删改。

**配音与离线复现**：音频缓存在 `tools/voiceover/vo00.mp3`～`vo06.mp3`，渲染脚本优先读缓存，缺则调用 `edge-tts` 合成写回，离线且无缓存时回退 macOS `say`（Tingting）。改词后删掉对应 mp3 并编辑 `VOICEOVER` 即可重新合成。

**改词重渲染**：编辑 `tools/render_douyin_video.py` 顶部的 `VOICEOVER`（起点 / 文案）与 `SCENE_START`（8 个分镜起点），再执行 `python3 tools/render_douyin_video.py --output <路径.mp4>`。晓晓在 `+10%` 语速下约 5.3 字／秒；改词后请确认每段时长不越过下一镜头起点。
